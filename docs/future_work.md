# Future Work

Several directions can further improve the proposed framework.

## GUI-Specific Grounding Models

Future versions can replace general-purpose grounding models with GUI-specialized grounding networks trained specifically on mobile interfaces.

## Advanced Reinforcement Learning

More sophisticated reinforcement learning algorithms such as PPO (Proximal Policy Optimization) and A2C (Advantage Actor-Critic) can be explored to improve policy learning and action selection.

## Real-Time Interaction

The framework can be extended to support continuous screen streaming and real-time interaction, enabling more responsive automation.

## Larger Training Datasets

Increasing the number of interaction trajectories and training episodes can improve generalization and reinforcement learning performance.

## End-to-End Learning

Future systems may replace heuristic coordinate refinement strategies with fully learned policies that directly map observations to actions.

## Multimodal Mobile Agents

Integration with modern Vision-Language Models and reasoning agents could enable complex multi-step task execution across a wider range of mobile applications.
